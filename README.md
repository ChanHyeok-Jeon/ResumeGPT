# ResumeGPT (이력서GPT) · 이력서로 대화하는 채용 챗봇

> 구직자는 **내 이력서를 바탕으로 상담**을 받고, 기업은 **"Python 경험 있는 지원자 찾아줘"처럼 자연어로 인재를 검색**하는 웹 서비스

| | |
|---|---|
| **대회** | 교내 오픈소스 SW 활용 대회 |
| **기간** | 2025.04 ~ 2025.05 |
| **인원** | 4인 |
| **내 역할** | **PM**, **백엔드 전체** (Flask 라우팅, MySQL 설계, PDF 텍스트 추출, LLM 연동) |
| **결과** | 🏆 **실용성 부문 단정상**, 2025.06.23 |

<br>

## 문제

- 구직자는 자기 이력서의 강점과 보완점을 물어볼 곳이 마땅치 않습니다.
- 채용 담당자는 이력서를 한 장씩 열어 보며 조건에 맞는 사람을 찾아야 합니다.

## 해결

| 사용자 | 기능 | 동작 |
|---|---|---|
| 구직자 | 이력서 기반 상담 | 가입할 때 올린 PDF 이력서를 PyMuPDF로 텍스트로 바꾸고, 질문과 함께 LLM에 전달 |
| 기업 | 자연어 인재 검색 | 등록된 구직자 이력서를 모아 LLM에 전달하고, 질문 조건에 맞는 지원자를 추천 |
| 기업 | 이력서 다운로드 | DB에 저장된 원본 PDF를 내려받기 |

```
[로그인 (구직자 / 기업)]
        ↓
[질문 입력] → /ask
        ↓
[MySQL에서 이력서 PDF 조회] → [PyMuPDF 텍스트 추출]
        ↓
[OpenRouter (GPT-3.5) 호출] → [답변 표시]
```

## 기술

Python · Flask · MySQL · PyMuPDF · OpenAI SDK (OpenRouter) · HTML/CSS/JS

## 실행

```bash
cd ResumeGPT
pip install -r requirements.txt
mysql -u root -p < database/init.sql
cp .env.example .env   # OpenRouter API 키 입력
python app.py
```

## 회고 · 다시 만든다면

- **비밀번호를 평문으로 저장했습니다.** 지금이라면 해시(bcrypt)로 저장하겠습니다.
